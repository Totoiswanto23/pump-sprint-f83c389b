A launch-sniper paper bot for pump.fun: it buys in the first few slots of a launch that passes a rug filter, then exits fast on take-profit, stop-loss or a creator sell. Tuned for the 6-hour sprint window — the guardrail probe pace matches a 6-hour window, so it stays above the 20-coin bar even in a short replay.

## Run it

```sh
node main.ts
```
